# Video Explorer – نسخه اولیه

اپلیکیشن اندرویدی آفلاین برای نمایش و پخش ویدیوهای موجود در چند پوشه انتخابی.

## امکانات پیاده‌سازی‌شده در اسکلت اولیه
- رابط شبکه‌ای ویدیوها
- پخش تمام‌صفحه با پیمایش عمودی
- انتخاب چند پوشه با Storage Access Framework
- نگهداری مجوز پوشه‌ها پس از بسته‌شدن برنامه
- اسکن مجدد هنگام ورود به برنامه و دکمه به‌روزرسانی
- پیمایش زیرپوشه‌ها و تشخیص فرمت‌های رایج ویدیو

## ساخت
1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle همگام‌سازی شود.
3. دستگاه اندرویدی یا شبیه‌ساز با Android 8.0 یا بالاتر انتخاب کنید.
4. از Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.

## نکته مهم نسخه اولیه
این نسخه نقطه شروع قابل توسعه است و هنوز نسخه نهایی و تست‌شده روی دستگاه واقعی نیست. اسکن خودکار در این مرحله هنگام بازگشت به برنامه و با دکمه تازه‌سازی انجام می‌شود؛ پایش لحظه‌ای تغییرات پوشه‌های SAF، ساخت پایگاه داده پایدار، تصویر بندانگشتی واقعی، مدیریت خطاهای فایل و تست سازگاری دستگاه‌ها در مراحل بعد تکمیل می‌شوند.
